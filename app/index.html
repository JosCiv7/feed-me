Feed Me

Zelf nieuw nieuws laten ophalen

GitHub slaat zijn vaste updates soms urenlang over. Met een sleutel kan deze knop zelf een update starten (± 8 minuten). Je doet dit maar één keer:

  1. Open deze GitHub-pagina en meld je aan.
  2. Naam: Feed Me. Vervaldatum: zo lang mogelijk.
  3. Bij Repository access: Only select repositories → feed-me.
  4. Bij Permissions: Actions → Read and write. Verder niets.
  5. Tik op Generate token, kopieer de sleutel en plak hem hieronder.

De sleutel blijft enkel op dit toestel en kan alleen updates van Feed Me starten.
